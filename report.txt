  limits; archived implementations remain.
- Best evidence for our claim: fitted low-rank bridge preserves PPL where a
  single affine map (Assignment 1 style) fails across multiple layers.

3. Datasets

4. Experimental plan
- Models: openai-community/gpt2 (124M params), HuggingFaceTB/SmolLM-135M (135M).
- Differences: GPT-2 uses blocks in model.transformer.h; SmolLM uses
  model.model.layers (Llama-style). Helpers get_layers/set_layers handle both;
  parameter counts above.
- Robustness on limited compute: single SEED=42; same eval windows for every
  model; random-removal control; ranks/bitwidths swept instead of one point.

- Metric: next-token perplexity on the validation split, because it is the
  metric in the supplied TerGRASP notebook and the most sensitive to block

II. EXPERIMENT

1. Implementation
- Code in assignment2.ipynb implements the full pipeline: dataset prep,

  ternary quantization, block swap, PPL/latency/params evaluation.

2. Results
Fitted-ternary TerGRASP PPL by k (validation):
  GPT-2:          k=1 45.11, k=2 50.09, k=3 140.42, k=4 879.52
  SmolLM-135M:    k=1 21.71, k=2 40.49, k=3 33.05, k=4 38.49
Hard-removal control:
  GPT-2:          45.76 / 47.95 / 121.81 / 943.24
  SmolLM-135M:    19.93 / 26.13 / 29.91 / 34.20
Reading: at k=1 the fitted bridge matches or slightly beats hard removal
while keeping the layer in the graph at ~1.58 bit/param. Higher k tracks
hard removal. This satisfies the hypothesis for k=1, weakens for k>=3.

3. Findings and patterns
- BI ranking works: targeted k>=2 removal beats random 3x-30x.
- k=1 is free for either method - one block is rarely critical.
- Affine/naive-merge/tying variants fail because layer maps are not
  affine and neurons are not aligned; fitted low-rank bridge + ternary
  quantization is the minimal change that preserves PPL.
- Low-BI layers tolerate 2-bit quantization with no PPL change, so BI
  predicts both removability and compressibility.
